# Estudos de POO (Java) ☕

Este repositório é focado nos conceitos de Programação Orientada a Objetos que estou aprendendo nas aulas de ADS e em cursos online. Aqui documento minha evolução técnica através de exercícios práticos.

---

## 📁 O que já tem aqui:

### 01. Criando Classes e Objetos
* Prática inicial de como estruturar classes, atributos e métodos.

### 02. Encapsulamento e Interfaces
* Exercícios focados em esconder detalhes do código (Private/Public) e usar Interfaces para organizar as funções.

### 03. Agregação entre Objetos
* Projetos como o **UfcCombat** e **ProjetoLivro**, que demonstram como objetos de classes diferentes interagem entre si.

### 04. Herança
* Implementação de hierarquias de classes, explorando o uso de classes abstratas e a reutilização de código.

### 05. Polimorfismo
* **Sobreposição (Override)**: Métodos que se comportam de forma diferente em cada classe filha (Ex: Animais).
* **Sobrecarga (Overload)**: Múltiplas formas de um mesmo método reagir baseando-se nos parâmetros (Ex: Reações do Cachorro).
